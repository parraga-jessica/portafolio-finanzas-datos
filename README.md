# Portafolio · Contabilidad, Finanzas y Datos

Estudiante en etapa práctica del Técnico en Contabilización de Operaciones Comerciales y Financieras, construyendo el cruce entre contabilidad, finanzas y análisis de datos. Busco mi primera práctica como analista financiero o de BI.

Este repositorio documenta los proyectos que voy desarrollando: modelos de Excel, consultas SQL, tableros de BI y automatizaciones aplicadas a casos financieros.
